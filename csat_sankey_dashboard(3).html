Правила

Для анализа остаются только сессии с точкой ASR_CSI VOICE ГМ.
Оценка определяется по payload_label: 1–5, «больше 5» → 5, «меньше 1» → 1.
Внешние кавычки и лишние/невидимые пробелы очищаются.
Если в сессии несколько оценок — используется последняя по num_phrase.
